# Security

## Reporting a vulnerability

Please don't open a public issue. Report it privately instead: open the **Security** tab of this repository and choose **Report a vulnerability** ([direct link](https://github.com/LenderCom/bydawn-dryrun/security/advisories/new)). Only the maintainers can read it.

Tell us what you found, how to reproduce it, and what it lets someone do. We'll acknowledge it within three working days, keep you posted while we fix it, and credit you in the advisory unless you'd rather we didn't.

## Supported versions

We fix security problems in the latest release. Upgrade to get the fix. There are no long-term branches.

## How we ship

Every release is built in CI from a tag and published with provenance, so you can check that the package you installed came from this repository.
